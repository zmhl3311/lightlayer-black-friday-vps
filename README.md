## 退款窗口和流量超量，比价格更该先看

## FAQ

**黑五当天会不会更便宜？**
已开卖的商家大多把活动窗口拉到11月底甚至12月中，黑五正日再叠加一轮的概率不高。LightLayer 的双十一帖标题写黑五、内容是双十一，说明它把这一档当成本季主促。真等27号，可能只是看着别人买。

**续费会不会涨？**
LightLayer 和 NoslaCloud 写明续费同价；Friendhosting 只便宜首期；Hostinger 从 $6.49 涨到 $11.99。下单页的续费价才是长期成本。

**能不能退款？**
LightLayer 只处理商家原因；NoslaCloud 24小时内、流量少于5GB可退；华纳云独服不可退；EDIS 用码不可退；RackNerd VPS 不退款。先确认再付款。

**优惠码能叠吗？**
LightLayer 官方说季付、半年付、年付可同享活动并可叠加额外优惠，具体叠什么要问客服。RakSmart 的秒杀款明确不叠券。其余商家多数一款一码，别默认能叠加。

**流量超了会怎样？**
NoslaCloud 限速到1KB，RackNerd 限速10Mbps，两者体验差一个量级。买之前按自己的月流量需求选档，别指望超量后还能正常用。
